# Документация проекта синхронизации Microsoft To Do и Kaiten

## Обзор

Проект представляет собой приложение для автоматической синхронизации задач между Microsoft To Do и Kaiten с корректной обработкой часовых поясов (Сахалинск, UTC+11). Поддерживает двустороннюю синхронизацию, принудительную синхронизацию и полный сброс синхронизации.

## Особенности

- Поддержка нестандартных форматов дат Microsoft To Do
- Корректное преобразование дат с учетом часового пояса Сахалинска (UTC+11)
- Двусторонняя синхронизация задач
- Хранение сопоставлений задач в файле `sync_mapping.json`
- Поддержка запуска как модуля и как отдельного файла
- Возможность принудительной синхронизации
- Скрипт полного сброса синхронизации

## Структура проекта

```
kaiten_todo/
├── src/                     # Исходный код приложения
│   ├── config/              # Конфигурация приложения
│   ├── exceptions/          # Определение исключений
│   ├── utils/               # Вспомогательные функции
│   ├── clients/             # Клиенты для работы с API
│   │   ├── todo_client.py   # Клиент Microsoft To Do
│   │   └── kaiten_client.py # Клиент Kaiten
│   ├── engines/             # Движки синхронизации
│   │   ├── sync_engine.py   # Основной движок синхронизации
│   │   └── force_sync_engine.py # Движок принудительной синхронизации
│   └── main.py              # Точка входа в приложение
├── reset_sync.py            # Скрипт полного сброса синхронизации
├── tests/                   # Тесты
├── docs/                    # Документация
├── config/                  # Конфигурационные файлы
├── requirements.txt         # Зависимости
├── .vscode/                 # Конфигурация VSCode
│   └── launch.json          # Конфигурация запуска в VSCode
└── README.md                # Основная документация
```
